## 🚀 Чем я занимаюсь

Я делаю проекты на **вайб-кодинге**: описываю задачу, веду ИИ-инструменты по шагам и довожу результат до рабочего продукта. Это быстрее и дешевле классической разработки, но с тем же вниманием к деталям: понятное ТЗ, продуманная логика, аккуратный интерфейс и проверка перед сдачей.

Мои проекты помогают малому бизнесу принимать заявки, считать стоимость, вести задачи и не терять клиентов.

## 🧩 Что я создаю

### 🤖 Боты и ИИ-агенты
- **Чат-бот для салона красоты.** Записывает клиентов и выгружает данные в Excel для администратора.
- **Бот для компании по остеклению и отделке балконов.** Принимает заявки с Авито и Директа, записывает на замер через Telegram.
- **ИИ-агент для компании-продавца промышленного оборудования.** Обрабатывает заявки в Telegram и передаёт их в amoCRM.

### 🧮 Калькуляторы
- **Калькулятор стоимости ремонта квартир.** Считает цену по типу жилья, площади и тарифу.
- **«Трансфер Про».** Приложение для ПК, которое считает стоимость проезда между городами.
- **Калькулятор цены и маржи для Яндекс Маркета.** Помогает выставить цену с учётом расходов маркетплейса.

### 🌐 Сайты и лендинги
- **Сайт-визитка для психолога.**
- **Сайт-визитка для мастера по сборке ПК.**
- **Мини-лендинг на Яндекс КИТ.**

### 📋 Системы управления
- **Система задач на Канбан-досках.**
- **Канбан-доска на PHP** для контроля этапов производства.
- **Трекер для курьеров** с Telegram-ботом и админ-панелью.

## 🤝 Как я работаю

| Этап | Что происходит |
|------|----------------|
| 💡 **От идеи до запуска** | Беру проект целиком: от первой идеи до работающего результата |
